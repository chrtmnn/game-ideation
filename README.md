Collection of skills for AI agents to support game ideation and early development workflows

## Install

Install all skills interactively:

```bash
npx skills add chrtmnn/game-ideation
```

List available skills:

```bash
npx skills add chrtmnn/game-ideation --list
```

Install one skill:

```bash
npx skills add chrtmnn/game-ideation --skill skill-123
```

Install globally for a specific agent:

```bash
npx skills add chrtmnn/game-ideation --skill skill-123 -g -a claude-code -y
```
