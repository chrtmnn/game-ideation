# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Purpose

A collection of skills for AI agents to support game ideation and early development processes. Skills in this repo are intended to be installed into Claude Code or similar agent harnesses.

## Repository Structure

This repo is in early/empty state. As skills are added, they will follow the Claude Code skill format — markdown files with frontmatter and structured prompt content that can be loaded via the Skill tool.
