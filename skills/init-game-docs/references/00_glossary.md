# Workshop Glossary — German ↔ English

Authoritative terminology mapping for the Daniel Dumont workshop series *"Von der Idee zum Konzept"* (Making Games Magazin 03/2010–02/2011). All workshop summaries in this folder use the English column consistently. When a future skill references the source PDF, this glossary is the single source of truth for translation choices.

## Core terms

| German (original) | English (used in summaries) | Notes |
|---|---|---|
| Spielidee | Game Idea | Stage 1 deliverable; the high-level vision |
| Spielmechanismus | Core Mechanic | Most important recurring action loop; carrier of fun |
| Exposé | Exposé | Loanword retained; ~20-page concise overview |
| Konzept / Spielkonzept | Game Concept | Detailed, continuously maintained design doc |
| Funktionsdesign | Functional Design | What the player sees and does |
| Logisches Konzept | Logical Concept | Internal rules, formulas, state, dependencies |
| Interface-Konzept | Interface Concept | HUD, controls, screens, camera |
| Feinkonzept | Detailed Design / fine-concept | Implementation-ready spec |
| Grobkonzept | Coarse Design / rough-concept | High-level structure before detailing |
| Änderungsmanagement | Change Management | Versioning and traceability process |
| Änderungslog | Change Log | Per-change ledger |
| Balancing | Balancing | Same in English |
| Extreme Balancing | Extreme Balancing | Dumont's named method |
| Wow-Effekt | Wow Factor / Wow Effect | First-glance visual appeal |
| Alleinstellungsmerkmal / USP | USP (Unique Selling Proposition) | Same |
| Visionierung | Visioning | The conceptual ideation work |
| Visionär | Visionary | The author who holds the vision |
| Konzeptautor | Concept Author / Designer | The writer of the design docs |
